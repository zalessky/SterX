# Правила работы с репозиторием

## Ветки
- Основная ветка — `feat/rolf-landing-page-1824583088472791334`. Все изменения коммитить в неё (или вливать в неё до релиза).
- Релизный тег ставится только на коммит, который уже есть в основной ветке. Не выпускать релиз из отдельной ветки.

## Релиз = деплой
- Появление тега `vX.Y` или `vX.Y.Z` запускает `.github/workflows/docker-image.yml`: образ `ghcr.io/zalessky/sterx` с тегами `latest` и `X.Y`. Сервер забирает `latest` автоматически — тег на неверном коммите сразу уходит на сайт.
- Перед тегом: поднять версию в `package.json` и `package-lock.json`, добавить запись в `CHANGELOG.md`, убедиться, что `npm run build` проходит.

## Сборка
- Сайт собирается в статику (`output: 'export'` в `next.config.mjs`). Не добавлять API routes, server actions, `next/image` с оптимизацией и прочее, что требует сервера Node.js, — в образе только nginx.
- `Dockerfile` и `deploy/nginx-site.conf` относятся к развёртыванию; менять осознанно.
